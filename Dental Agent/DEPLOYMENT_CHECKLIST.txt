# DEPLOYMENT CHECKLIST - Dental Clinic Agent
# Follow these steps IN ORDER

## STEP 1: On Your Laptop (Development Computer)
[ ] Copy these files to your external hard drive:
    - dental_agent.py
    - config.json
    - requirements.txt
    - README.md
    - DEPLOYMENT_CHECKLIST.txt (this file)
    - CLINIC_SETUP_GUIDE.txt

[ ] Download Python installer:
    - Go to: https://www.python.org/downloads/
    - Download: "Python 3.11.x" (Windows installer 64-bit)
    - Save the installer to your external hard drive
    - File will be named something like: python-3.11.x-amd64.exe

## STEP 2: On Clinic Computer (Installation)
[ ] Connect your external hard drive to the clinic computer

[ ] Create a folder on the clinic computer:
    - Recommended location: C:\DentalAgent
    - Copy ALL files from hard drive to this folder

[ ] Install Python:
    - Run the python-3.11.x-amd64.exe installer from your hard drive
    - ⚠️ IMPORTANT: Check "Add Python to PATH" on first screen
    - Click "Install Now"
    - Wait for installation to complete
    - Click "Close"

[ ] Install Python libraries:
    - Open Command Prompt (search "cmd" in Start menu)
    - Type: cd C:\DentalAgent
    - Press Enter
    - Type: pip install -r requirements.txt
    - Press Enter
    - Wait for installation (takes 1-2 minutes)

## STEP 3: Configure the Agent
[ ] Run the agent:
    - In the same Command Prompt window
    - Type: python dental_agent.py
    - Press Enter
    - The application window should open

[ ] Verify Settings (Settings Tab):
    - One2 Executable should show: C:\OSSTEM\OneVision\One2\oov.exe
    - One2 Export should show: C:\OSSTEM\OneVision\One2\oov.acq\acquired

[ ] Test the paths:
    - Click "Browse" next to One2 Executable
    - Navigate to: C:\OSSTEM\OneVision\One2\
    - Select: oov.exe
    - Click "Browse" next to One2 Image Export Folder
    - Navigate to: C:\OSSTEM\OneVision\One2\oov.acq\
    - Select: acquired folder
    - Click "Save Configuration"

## STEP 4: Update Server URL (IMPORTANT!)
⚠️ Before using with real patients, you MUST update the upload URL:

[ ] Open dental_agent.py in Notepad
[ ] Find line ~236 (search for "localhost:5000")
[ ] Change:
    FROM: "http://localhost:5000/api/upload"
    TO: "https://your-actual-clinic-server.com/api/upload"
[ ] Save the file
[ ] Close and reopen the agent

## STEP 5: First Test Run
[ ] Go to Session tab
[ ] Enter test Patient ID: TEST001
[ ] Click "Start Session"
    - One2 software should launch
    - Patient ID field should be locked
    - Status should show green/active
[ ] Take 1-2 test images with One2
[ ] Click "End Session"
    - One2 should close
    - Upload should occur (check for success message)

## TROUBLESHOOTING
If you see "offline" or "red status":
1. Check that oov.exe path is correct (file exists)
2. Check that acquired folder path is correct (folder exists)
3. Check Python is installed (type "python --version" in cmd)
4. Check internet connection for upload

If upload fails:
1. Verify the server URL is correct in dental_agent.py
2. Check that your Next.js server is running
3. Check firewall isn't blocking the connection

## NOTES
- Keep the external hard drive as backup
- The config.json file saves your settings
- You only need to install Python once
- After first setup, just run: python dental_agent.py
