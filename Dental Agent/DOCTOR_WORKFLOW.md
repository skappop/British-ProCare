# British ProCare - Doctor Workflow Guide

## Overview
This guide explains how doctors use the British ProCare system during patient appointments to capture, view, and manage clinical images efficiently.

---

## 🎯 Your Role
As a doctor, you focus on **patient care and clinical decisions**. The system handles image capture and organization automatically, so you can stay focused on diagnosis and treatment.

---

## 📋 Daily Workflow

### 1. **Before the Appointment**
The receptionist or assistant will have:
- ✅ Selected the active patient in the web system
- ✅ Started the Dental Agent on the clinic computer
- ✅ Verified the patient name appears in the agent

**What you see:**
- Patient gallery is open and ready
- Dental Agent shows: `🟢 Active Patient: [Patient Name]`

---

### 2. **During the Appointment**

#### **Taking Intraoral Photos (One2 Camera)**
1. The imaging software is already launched
2. Take photos as usual with the One2 camera
3. Photos save automatically to the export folder
4. **No manual steps needed** - just capture images

#### **Taking X-rays (EzDent-i)**
1. The X-ray software is already launched
2. Capture radiographs as usual
3. X-rays save automatically to the export folder
4. **Duplicate files are filtered** - only the best version uploads

#### **Focus on Your Work**
- No need to manually upload anything
- No need to rename files
- No need to organize folders
- **Just capture images normally**

---

### 3. **After the Appointment**

#### **Ending the Session**
1. Click **"End Session & Upload Images"** in the Dental Agent
2. Wait 10-30 seconds for upload to complete
3. Success message confirms upload

#### **Viewing Images Immediately**
1. Open the patient's gallery in the web app
2. All images from the session appear instantly
3. Images are automatically categorized:
   - 📷 **Intraoral** - One2 camera photos
   - 🦷 **Radiographs** - EzDent-i X-rays
   - 📄 **Documents** - PDFs, forms, etc.

---

## 🖥️ Using the Web System

### **Patient Gallery View**
Access: **Patients → [Patient Name] → Gallery**

**What you see:**
- Grid of all patient images organized by date
- Filter tabs: All / Intraoral / Radiographs / Documents
- Baseline images marked with gold star ⭐
- Image metadata (date taken, device used)

**Actions you can take:**
- **View full-size** - Click any image to open lightbox
- **Mark as baseline** - Click star icon for comparison images
- **Add notes** - Click image → Add clinical notes
- **Download** - Save image to local computer
- **Delete** - Remove incorrect/duplicate images

### **Viewing Patient History**
Access: **Patients → [Patient Name] → Overview**

**What you see:**
- Complete patient timeline
- All appointments and treatments
- Recent images at a glance
- Quick access to treatment plans

## 💡 Tips for Efficient Workflow

### **Multi-Patient Sessions**
If you see multiple patients in quick succession:
1. **Ask receptionist to change active patient** between appointments
2. Wait for Dental Agent to show new patient name
3. Proceed with imaging
4. System prevents accidental uploads to wrong patient

### **Session Timeout Protection**
- Sessions auto-end after 60 minutes (configurable)
- You'll get a warning at 50 minutes
- This prevents forgotten sessions from staying open overnight

### **Mid-Session Software Launch**
Need X-rays after starting with intraoral photos?
1. Click **"🦷 Launch EzDent-i"** in the Dental Agent
2. Both systems run simultaneously
3. All images upload together at session end

### **Review Before Finalizing**
Before ending the session:
1. Check image count in export folders
2. Verify all desired images were captured
3. Retake any unclear images while software is still open

## 🔍 Image Quality Checklist

### **Intraoral Photos (One2)**
- ✅ Sharp focus on target area
- ✅ Good lighting (no shadows or glare)
- ✅ Proper isolation (cheek retractors used)
- ✅ Full tooth/arch coverage as needed

### **Radiographs (EzDent-i)**
- ✅ Proper positioning (no cone cuts)
- ✅ Correct exposure (not too dark/light)
- ✅ Patient centered in frame
- ✅ Anatomical landmarks visible

**Note:** Poor quality images can be retaken immediately. After session ends, you'll need to start a new session to capture additional images.

## 📊 Analyzing Patient Progress

### **Comparing Baseline Images**
1. Open patient gallery
2. Find original baseline image (marked with ⭐)
3. Open recent image in lightbox
4. Toggle between baseline and current image
5. Document changes in treatment notes

### **Treatment Documentation**
For each significant image:
1. Click image thumbnail
2. Add clinical notes describing:
   - What the image shows
   - Why it was taken
   - Clinical significance
   - Treatment decisions made
3. Notes are saved and visible to all team members

## 🚨 Troubleshooting

### **"No Images Found" Warning**
**Possible causes:**
- Images still processing in software
- Export folders not configured correctly
- No images were actually captured

**Solution:**
1. Check the imaging software - are images visible there?
2. Wait 30 seconds for processing
3. Try ending session again
4. If still no images, check Settings tab in Dental Agent

### **Wrong Patient Selected**
**If you notice during session:**
1. System will detect active patient change
2. You'll see dialog: "Session Already Active"
3. Choose:
   - **Yes** = End current & upload
   - **No** = Discard current (no upload)
   - **Cancel** = Keep current session

**Prevention:**
- Always verify patient name in Dental Agent before capturing images
- Ask receptionist to double-check active patient selection

### **Upload Failed**
**Possible causes:**
- No internet connection
- Server temporarily unavailable
- API key configuration issue

**Solution:**
1. Check internet connection
2. Try ending session again (images are still saved locally)
3. Contact clinic administrator if persistent
